## 🌟 أبرز مميزات التحديث الشامل (UI/UX 2.0 Overhaul)

### 1. 🎯 إعادة تصميم الواجهة حول المهمة الأساسية: إنجاز عادات اليوم
- **التركيز البصري المباشر:** وضع عادات اليوم والتقدم الفعلي في صدارة الشاشة لتقليل التشتت البصري.
- **مؤشرات تقدم حقيقية وصادقة:** عرض دقيق لعدد العادات المنجزة مقابل العادات المستحقة (`X من Y عادات مكتملة اليوم بنسبة Z%`) مع حظر تام لأي نسب وهمية أو تضخيم غير مدعوم ببيانات حقيقية.
- **حالة استهلالية ترحيبية (Welcoming Zero State):** عند فتح التطبيق لأول مرة أو بدون عادات، يظهر للمستخدم كارت ترحيبي جذاب يتيح له إضافة عادات أساسية بنقرة واحدة (ماء، قراءة، رياضة، أذكار).
- **فصل وضع تخصيص اللوحة (Bento Customization):** إخفاء أزرار التحجيم والسحب المزعجة في وضع الاستخدام اليومي المعتاد، وإظهارها فقط عند النقر على زر "تخصيص اللوحة" لتوفير واجهة هادئة خالية من الضوضاء.

### 2. ⚡ تدفق إنشاء العادات في أقل من 30 ثانية (Fast Habit Creation)
- **قوالب سريعة جاهزة (Quick Starter Templates):** شريط قوالب علوي في نافذة الإضافة يتيح تعبئة بيانات العادة الأساسية بنقرة واحدة (شرب 8 أكواب ماء، قراءة 15 دقيقة، رياضة 30 د، أذكار واستغفار، عمل عميق، نوم مبكر).
- **3 آليات تتبع أساسية وواضحة:**
  1. **إنجاز بنقرة واحدة (Check ✅):** للعادات البسيطة المباشرة.
  2. **عداد وكمية (Counter 🔢):** مع إظهار حقول الهدف والوحدة والخطوة فقط عند اختيار هذا النمط.
  3. **مؤقت تركيز (Timer ⏱️):** لتتبع المدة الزمنية بالدقائق.
- **طي الإعدادات المتقدمة في قائمة منسدلة أنيقة (Collapsible Accordion):** تجميع خيارات فترة اليوم، التصنيفات، التكرار الأسبوعي، تراكم العادات، والعادة المصغرة للأيام الشاقة في قسم متقدم اختياري لا يعيق الإنشاء السريع.
- **نافذة تأكيد مخصصة (Custom Bento Confirmation Modal):** استبدال تنبيهات المتصفح التقليدية بنوافذ تأكيد بتصميم Apple توضح بوضوح الفارق الجوهري بين **تصفير السجل فقط** (إبقاء العادة وتصفير السلسلة) و**حذف العادة كلياً** (مسح العادة وسجلها نهائياً).

### 3. ⌨️ لوحة الأوامر الشاملة (Universal Command Palette - `⌘K`)
- اختصار سريع `⌘K` أو `Ctrl+K` أو عبر زر البحث العلوي يتيح:
  - البحث الفوري في قائمة العادات وإنجازها أو التراجع عنها بضغطة واحدة من داخل اللوحة.
  - التنقل الفوري بين الأدوات الـ 15 المتكاملة.
  - التبديل السريع بين لوحات التطبيق (اليوم، المهام، التحليلات، الأدوات، التثبيت) بالاختصارات `1` و `2` و `3` و `T`.
  - إجراءات سريعة لتفعيل وضع الهدوء، تبديل المظهر، وبدء سلاسل الروتين.

### 4. 🧘‍♂️ وضع التركيز الهادئ (Zen Mode)
- زر مخصص «🧘‍♂️ زن» يخفي المشتتات والشرائط الجانبية للتركيز الكامل على قائمة عادات اليوم، مع حفظ التفضيل محلياً.

### 5. ⚡ الإنجاز المجمّع لعادات الروتين (One-Tap Batch Routine Complete)
- زر «⚡ إنجاز الكل» لإتمام عادات روتين الصباح أو المساء بلمسة واحدة مع اهتزاز لمسي مزدوج، نغمة احتفالية، ومكافأة +50 XP.

## ♿ معايير إمكانية الوصول (WCAG 2.2 AA Compliance)

تم تدقيق وتحسين الواجهة البرمجية لتلبي معايير الوصول العالمية:
1. **دعم التكبير البصري حتى 200% (Visual Zooming):**
   - إزالة قيود الحظر `maximum-scale=1.0, user-scalable=no` من وسوم `viewport` في كافة الصفحات واعتماد `<meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover">`.
2. **نسب التباين اللوني المعتمدة (Contrast Ratio):**
   - تحقيق نسبة تباين لا تقل عن **4.5:1** للنصوص العادية وأكثر من **3:1** للنصوص الكبيرة والأيقونات في كلا الوضعين الفاتح والداكن (`--text-primary: #0A0C10` و `--text-secondary: #374151` في الوضع الفاتح، و `#F9FAFB` و `#CBD5E1` في الوضع الداكن).
3. **مساحات اللمس القياسية (Touch Targets):**
   - ضبط الحد الأدنى لكافة الأزرار والكبسولات وحقول الإدخال إلى **44 × 44 بكسل** لضمان سهولة النقر على الهواتف والأجهزة اللوحية دون أخطاء.
4. **دعم تقليل الحركة (Prefers-Reduced-Motion):**
   - تطبيق استعلام `@media (prefers-reduced-motion: reduce)` لإيقاف حركات الارتداد والرسوم المتحركة للمستخدمين الذين يفضلون التنقل الهادئ.
5. **إمكانية التنقل بلوحة المفاتيح والـ ARIA:**
   - ضبط دلالات النوافذ المنبثقة `role="dialog"` و `aria-modal="true"`.
   - إدارة انتقال التركيز ودعم الإغلاق بزر `Escape`.
   - إزالة المنع العام لتحديد النصوص (`user-select: none`) لتمكين القراءة والنسخ الطبيعي.

## 🌍 التوطين العربي الكامل وتجربة RTL (Arabic Localization)

- **تعريب شامل 100%:** استبدال المصطلحات الإنجليزية بالكامل بمصطلحات عربية فصيحة ومعبرة:
  - `Single` ➔ `يومي`
  - `Weekly` ➔ `أسبوعي`
  - `Yearly` ➔ `سنوي`
  - `Left` ➔ `الوقت المتبقي`
  - `Theme Color` ➔ `لون السلسلة والمخطط`
  - `S / M / L / Full` ➔ `صغير / وسط / عريض / كامل`
- **محاذاة وانسيابية النصوص:** ضبط الاتجاه `dir="rtl"` وتنسيق النصوص والأرقام والنسب المئوية ومربعات الاختيار لتعمل بتناسق تام مع طبيعة القراءة واللمس باللغة العربية.

├── تشغيل_التطبيق.command         # تشغيل فوري وسريع بنقرة واحدة على macOS
├── README.md                    # هذا الملف: الوصف العام وتوثيق التحسينات ومعايير الوصول
├── GUIDELINES.md                # المرجع الفني والهندسي الشامل
├── TESTING_PLAN.md              # خطة الاختبار المبدئي وتدقيق السيناريوهات
├── UI_UX_IMPROVEMENT_PLAN.md    # وثيقة تخطيط تحسينات واجهة وتجربة المستخدم
│
├── css/
│   ├── theme.css                # متغيرات التصميم (Tokens)، التباين اللوني، والألوان الدلالية
│   ├── layout.css               # الهيكل الشبكي المتجاوب لكافة الشاشات والأجهزة

└── js/
    ├── app.js                   # المحرك الرئيسي، إدارة النوافذ، والحسابات الإحصائية الدقيقة

        ├── auth-manager.js      # نظام إدارة الحسابات المتعددة وعزل البيانات
        ├── tools-data.js        # السجل المصدري لبيانات ومراجع الأدوات الـ 15

        ├── plugin-system.js     # نظام تسجيل الإضافات وتفعيلها مع الـ Hooks
        ├── widget-registry.js   # إدارة بطاقات البينتو وترتيبها وتخصيصها
        ├── canvas-engine.js     # محرك لوحة البينتو الحرة (Universal Bento Canvas)
        └── drag-drop.js         # محرك السحب والإفلات المتوافق مع اللمس والماوس

## 🚀 التشغيل والتثبيت المحلي

### تشغيل فوري على نظام Mac:
انقر نقراً مزدوجاً على ملف `تشغيل_التطبيق.command` ليتم فتح التطبيق مباشرة في متصفحك.

### تشغيل عبر أي خادم محلي:
```bash
# عبر Python 3
python3 -m http.server 8080

# أو عبر Node.js
npx serve .
```
ثم افتح: `http://localhost:8080`
