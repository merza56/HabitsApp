## 🌟 أبرز المميزات (Core Highlights)

### 1. 🍱 لوحة البينتو الحرة التفاعلية (Universal Bento Canvas)
* **تخصيص حر وسحب وإفلات:** إمكانية إعادة ترتيب كافة الويدجتس بالسحب والإفلات المباشر على الهاتف (Touch) والكمبيوتر (Mouse) دون أي ارتباك في التخطيط.
* **نظام التحجيم الرباعي الذكي (`S` / `M` / `L` / `Full`):** تحويل أي ويدجت بين القياس المصغر للمؤشرات السريعة، أو القياس الكامل للمخططات والجداول التفاعلية.
* **معرض ويدجتس يضم 25 بطاقة متخصصة:** تفعيل وإخفاء وتخصيص أي ويدجت من نافذة المعرض المنظمة حسب الفئات.

### 2. ⚡ ميزات مجتمع الإنتاجية العالمية (Community Power Features)
* **بنك تجميد السلاسل وأيام الراحة المبررة (Streak Freeze Bank 🧊):** حل جذري لأزمة "قلق السلاسل" (Streak Anxiety). رصيد تجميد (حتى 3 رموز) يحمي سلسلتك عند المرض أو السفر أو أيام الراحة دون تصفير العداد.
* **الأهداف الأسبوعية المرنة (Flexible Weekly Frequency 🎯):** تتبع العادات غير اليومية مثل الذهاب للجيم (3 أو 4 أيام أسبوعياً) مع رصد مرن للتقدم الأسبوعي.
* **العادة المصغرة للأيام الشاقة (Show-Up Mini-Habits 🌱):** تطبيق قاعدة الدقيقتين لجيمس كلير عبر زر إنجاز مصغر يحافظ على المسار العصبي ويمنح +5 XP.
* **نظام الرتب ونقاط الخبرة السلوكية (Gamified XP & Levels ⚡):** تدرج في 6 مستويات هوية تصاعدية (من مبتدئ النشاط 🌱 إلى سيد التدفق الذهني 👑).
* **مشغل سلاسل الروتين (Morning/Evening Routine Flow Runner 🌅 / 🌙):** جلسة تركيز تفاعلية موجهة تأخذك عبر عادات الصباح أو المساء خطوة بخطوة مع مؤثرات صوتية ناعمة.

### 3. 📊 حزمة التحليلات السلوكية الفائقة (25+ Analytics Suite)
* **سيكولوجية الأسبوع وأيام الذروة (Day-of-Week Peak & Dip):** تحليل إحصائي لمعدل الالتزام عبر الأيام السبعة لاكتشاف يوم القمة وأيام الهبوط.
* **رادار توازن مجالات الحياة (Holistic Life Balance):** توزيع الالتزام على الصحة والعمل والرياضة والتطوير والروحانية.
* **مصفوفة الارتباط والتآزر السلوكي (Habit Correlation Catalysts):** رصد العادات المحفزة (Keystone Habits) وتأثيرها على العادات الأخرى.
* **الرصد الوقائي لخطر التعثر (Drop-off Risk Predictor):** إنذار مبكر للعادات المهددة بالانقطاع قبل كسر السلسلة.
* **مؤشر قوة العادة التراكمي (Habit Strength Index 30d):** قياس ترسخ العادة في المسار العصبي.
* **منحنى الإيقاع الحيوي وساعات التدفق (Circadian Rhythm 24h):** رصد فترات قمة الطاقة الصباحية وفترات الخمول اليومي.
* **عداد النقاء والعائد المالي والصحي (ROI Ticker):** حساب الأموال والساعات المحفوظة من كسر العادات السلبية.
* **بانوراما الـ 365 يوماً السنوية والخريطة الحرارية الشهرية:** متابعة شاملة للالتزام على مدار العام بأسلوب GitHub و Left.

### 4. 🔒 خصوصية مطلقة وتطبيق محلي (100% Local-First)
* كافة العادات والمهام والتحليلات تُحفظ محلياً في متصفحك عبر `localStorage`.
* دعم كامل للعمل دون اتصال بالإنترنت عبر Service Worker v4 (Offline-First).
* إمكانية تصدير واستيراد نسخة احتياطية كاملة بصيغة JSON بنقرة واحدة.

## 📱 التجاوب عبر كافة الشاشات (Responsive Breakpoints)

تم اختبار وضبط النظام ليعمل بكفاءة مطلقة وفق معايير Apple Human Interface Guidelines:

| نوع الجهاز | العرض (Viewport) | نظام الأعمدة | خصائص التجاوب |
| :--- | :--- | :--- | :--- |
| **الهواتف الذكية (iPhone / Android)** | `< 640px` | عمود واحد مرن (`1fr`) | نصوص مرنة بـ `clamp()`، منع خروج البطاقات عن الشاشة، دعم نتوء الكاميرا وشريط Home السفلي بـ `safe-area-inset`. |
| **الأجهزة اللوحية (iPad / Tablets)** | `640px - 1023px` | عمودان متوازنان (`2 cols`) | شريط تنقل مكتبي مدمج، توزيع متوازن للبطاقات، شاشات مقسمة للتحليلات. |
| **سطح المكتب والشاشات الكبيرة** | `≥ 1024px` | 3 أعمدة متناسقة (`3 cols`) | استغلال ذكي للمساحة العريضة مع الحفاظ على راحة العين والتركيز على المركز. |

## 🏗️ المعمارية البرمجية (System Architecture)

تم بناء المشروع وفق معمارية برمجية قياسية حديثة بدون أطر عمل ثقيلة لضمان أعلى أداء واستجابة فورية:

```text
HabitsApp/
├── index.html                   # هيكل الـ DOM الدلالي واللوحات الرئيسية
├── manifest.json                # إعدادات الـ PWA والتثبيت على الشاشة الرئيسية
├── icon.svg                     # أيقونة المتجه التفاعلية
├── sw.js                        # الـ Service Worker والتخزين المؤقت دون إنترنت (v4)
├── README.md                    # هذا الملف: الوصف العام وطريقة الاستخدام
├── GUIDELINES.md                # الدليل الهندسي والمعماري للمشروع
├── CONTRIBUTING.md              # دليل المطورين والمساهمة
├── تشغيل_التطبيق.command         # تشغيل محلي بنقرة واحدة لأجهزة Mac
│
├── css/
│   ├── theme.css                # لوحة ألوان البينتو الباستيلية، الظلال، وأوضاع العرض
│   ├── layout.css               # هيكلة الشاشات، الشريط الكبسولي، ونقاط التجاوب
│   └── components.css           # بطاقات البينتو، العدادات، والويدجتس السلوكية
│
└── js/
    ├── app.js                   # منطق الواجهة وربط التفاعلات
    └── core/
        ├── event-bus.js         # ناقل الأحداث المركزي (Publish/Subscribe)
        ├── plugin-system.js     # نظام الإضافات المفتوح وخطافات دورة الحياة
        ├── widget-registry.js   # إدارة دليل الويدجتس وترتيب اللوحة
        ├── drag-drop.js         # محرك السحب والإفلات الموحد للمس والفأرة
        └── canvas-engine.js     # محرك اللوحة الحرة والتحجيم والويدجتس المتقدمة
```

### دورة حياة الأحداث المركزية (EventBus Pattern)
تعتمد المكونات على ناقل أحداث موحد `HabitFlowEventBus`، مما يجعل كل ويدجت مستقلاً بالكامل:
```javascript
// الاستماع لحدث إتمام العادة
window.HabitFlowEventBus.on('habit:toggled', ({ habit, isDone }) => {
  console.log(`تم تغيير حالة العادة: ${habit.name}`);
});

// بث حدث تحديث البيانات
window.HabitFlowEventBus.emit('data:updated', { source: 'canvas' });
```

## 🚀 التثبيت والتشغيل المحلي (Quick Start)

### 1. التشغيل السريع على أجهزة Mac
* افتح المجلد وانقر نقراً مزدوجاً على ملف:
  ```bash
  تشغيل_التطبيق.command
  ```
  سيقوم تلقائياً بتشغيل خادم محلي وفتح التطبيق في متصفحك الافتراضي.

### 2. التشغيل عبر سطر الأوامر (أي نظام تشغيل)
يمكنك استخدام أي خادم محلي ثابت:
```bash
# باستخدام Python 3
python3 -m http.server 8080

# أو باستخدام Node.js
npx serve .
```
ثم افتح الرابط: `http://localhost:8080`

### 3. التثبيت كـ PWA على الهاتف
* **أجهزة iPhone (Safari):** اضغط على زر المشاركة (Share) ➔ اختر **"إضافة إلى الصفحة الرئيسية" (Add to Home Screen)**.
* **أجهزة Android (Chrome):** اضغط على القائمة (⋮) ➔ اختر **"تثبيت التطبيق" (Install App)**.
